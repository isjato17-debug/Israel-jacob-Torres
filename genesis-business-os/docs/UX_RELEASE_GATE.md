# UX Release Gate
Mobile-first consumer UI must support:
- loading, empty, offline/network error, permission denied and provider unavailable states
- accessible labels/focus order/keyboard navigation and readable contrast
- 320px-wide viewport without horizontal overflow
- no destructive action without clear confirmation
- no dead primary CTA
- Home emphasizes one Next Turn
- advanced evidence/technical detail stays progressively disclosed
- Community has report/block/delete controls
- user can distinguish Prepared, Executed, Guided, Verified and Failed states
